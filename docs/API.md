\# Документация API



\## 1. Получение списка задач

\*\*Метод:\*\* `GET /api/tasks`



Возвращает список всех задач.



\*\*Параметры (query):\*\*

\- `limit` (int, опционально) — количество задач на странице (по умолчанию 10).



\*\*Ответ (200 OK):\*\*

```json

\[

&#x20;   "id": 1,

&#x20;   "title": "Сделать домашку",

&#x20;   "completed": false

&#x20; }
{
  "title": "Новая задача"
{
  "id": 2,
  "title": "Новая задача",
  "completed": false
}
}

]
